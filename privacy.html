1. Overview & Scope

This Privacy Policy describes how 60 Nodi Rahasiyam ("the application"), operated by developer harishharish988@gmail.com, collects, uses, stores, and protects Google user data accessed through Google API Services.

2. Google User Data Accessed

  • YouTube Data API v3 Upload Scope (https://www.googleapis.com/auth/youtube.upload): Used solely to upload video files and configure video metadata (titles, descriptions, tags, category IDs, and visibility status) on authorized YouTube channels owned by the developer.
  • Basic Channel Metadata: Read-only channel identification metadata used strictly to confirm the target channel before publishing.
  • OAuth 2.0 Tokens: Access and refresh tokens issued during authorization are stored privately in restricted runtime storage to execute scheduled video uploads.

3. How Data Is Used, Stored, and Protected

  • Purpose Limitation: Google user data is used exclusively to automate video uploads to the owner's YouTube channel.
  • No Third-Party Sharing or Sale: Data is never sold, rented, or shared with third parties, advertisers, or data brokers.
  • No AI/ML Model Training: Google user data is never used to train, fine-tune, or improve machine learning or artificial intelligence models.
  • Strict Prohibition of AI NCII: This application does not use Google APIs or any connected tools to create, edit, or publish AI-generated non-consensual intimate imagery (AI NCII).
  • Security Controls: OAuth credentials and refresh tokens are stored in private, access-controlled environments and are never exposed in public repositories.

4. Data Retention and Revocation

Data Type Retention Period Deletion & Revocation
OAuth 2.0 Access & Refresh Tokens Retained only while automated publishing is active. Deleted immediately upon removing local token files or revoking access.
Video Files & Upload Logs Temporary during upload execution. Purged automatically after upload completion.

You can revoke this application's access at any time via the Google Account Security Permissions page.

5. Google API Services User Data Policy

60 Nodi Rahasiyam's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
